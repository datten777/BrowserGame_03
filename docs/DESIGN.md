# 提案：GitHub Pages で遊べる成長型アクションRPG「灯火の継承者（ともしびのけいしょうしゃ）」

## Context
リポジトリ `BrowserGame_03` は空（コミットなし）。GitHub Pages の URL にアクセスするだけで遊べる、
HTML/CSS/JavaScript（ビルド不要・外部サーバー不要）のアクションRPGを新規に作る。
今回はストーリーのあらすじとゲームシステムの提案。承認後、この設計に沿って実装する。

---

## 1. ストーリーのあらすじ

**世界観**：世界は「灯台樹（とうだいじゅ）」が放つ光で闇から守られていた。ある夜、灯台樹が枯れ、
各地に「影獣（かげじゅう）」があふれ出す。

**主人公**：辺境の村の見習い木こり・リオ（名前は変更可）。剣の腕はまだ未熟。

| 章 | 舞台 | 内容 | 成長の節目 |
|---|---|---|---|
| 序章 | 森の村 | 村が影獣に襲われ、師匠が倒れる。最後に託された「種火のランタン」を手に旅立つ | 基本攻撃・回避を習得 |
| 1章 | 霧の森 | 森の守護者（巨大な狼）を影から解放。ランタンが最初の「灯火」を得る | スキル「火の斬撃」解放 |
| 2章 | 砂の遺跡 | 古代文明の遺跡で、灯台樹はかつて人の手で植えられたと知る | ダッシュ（壁越え・遠距離移動） |
| 3章 | 氷の峡谷 | ライバル剣士カイと衝突→共闘。カイは影の力で強くなろうとしている | 「氷の盾」＝ガード＆反撃 |
| 4章 | 沈んだ王都 | 影獣の正体は、灯台樹に光を吸われ続けた古い民の怨念だったと判明 | 「光の矢」遠距離攻撃 |
| 終章 | 枯れた灯台樹の根 | 影の王と対峙。倒すか、光と影を分け合う形で和解するかを選ぶ | 全灯火を集めた最終形態 |

**テーマ**：「受け継いだ小さな火を、自分の力で大きく育てる」。
マルチエンディング（2種：討伐エンド／共存エンド）で、4章までのサブクエスト達成度により共存エンドが解放される。

## 2. ゲームシステム

### 2.1 基本仕様
- **視点**：見下ろし型2Dアクション（ゼルダ風）。1画面ずつ切り替わるマップ（部屋単位）
- **技術**：素の HTML5 Canvas + ES Modules（ライブラリ・ビルド不要）。`index.html` を置くだけで GitHub Pages で動作
- **操作**：PC＝キーボード（移動 WASD/矢印、攻撃 J、スキル K、回避 L、メニュー Esc）／
  スマホ＝画面上の仮想パッド＋ボタン
- **グラフィック**：ドット絵風。初期はコード描画のシンプルな図形／小さなスプライトで作り、後から差し替え可能な構成
- **セーブ**：`localStorage` に自動セーブ（部屋移動・宿屋で保存）、3スロット

### 2.2 戦闘（アクション）
- 通常攻撃（3段コンボ）・回避ローリング（無敵時間あり）・スキル（MP消費）
- 敵ごとに攻撃予兆（点滅）を出し、見て避ける遊びを重視
- 各章の最後にボス戦。ボスは HP 段階で行動パターンが変化

### 2.3 成長システム（3本柱）
1. **レベルアップ**：敵を倒して経験値 → HP/MP/攻撃/防御が上昇。レベルごとに「ステータスポイント」3を自由振り
2. **灯火（アビリティ）**：ボス撃破で新能力を獲得。新能力で過去のマップの通れなかった場所に行ける（メトロイドヴァニア要素）
   - 火の斬撃：燃える茂みを焼き払う
   - ダッシュ：崩れた床・谷を飛び越える
   - 氷の盾：弾を跳ね返してスイッチを押す
   - 光の矢：遠くのスイッチを撃つ
3. **スキルツリー**：「剣」「灯火」「生存」の3系統。SP でスキル強化（例：コンボ4段目追加、回避後に攻撃力UP、HP自動回復）

### 2.4 装備・アイテム
- 装備枠：武器・防具・お守り（アクセサリ）の3つ。店と宝箱で入手
- 消耗品：回復薬、MP薬、帰還の羽（村へワープ）
- お金（ゴールド）は敵ドロップと宝箱

### 2.5 探索・その他
- 各章：フィールド（5〜8部屋）＋ダンジョン（6〜10部屋）＋ボス部屋
- 村を拠点に店・宿屋・サブクエスト受注
- 隠し部屋・「灯火のかけら」（4個でHP最大値UP）で寄り道の動機づけ
- 難易度：ノーマル／イージー（被ダメージ半分）

## 3. 実装方針（承認後）

**ファイル構成案**
```
index.html          ... エントリ（Canvas＋UI）
css/style.css
js/main.js          ... ゲームループ・シーン管理
js/input.js         ... キーボード／タッチ入力
js/player.js, js/enemy.js, js/combat.js
js/map.js, data/maps/*.js   ... 部屋データ（タイル配列）
js/ui.js            ... HUD・メニュー・会話ウィンドウ
js/save.js          ... localStorage セーブ
data/story.js       ... 会話・イベント
```

**開発ステップ**
1. 最小プロトタイプ：移動・攻撃・敵1種・部屋遷移・HUD（まず序章が遊べる状態）
2. レベルアップ／ステータス振り／セーブ
3. 1章（霧の森＋ボス）と「火の斬撃」＋アビリティによる通行解放
4. スキルツリー・装備・店
5. 2章以降のコンテンツ追加、エンディング分岐
6. スマホ操作対応・調整

GitHub Pages 公開：リポジトリ Settings → Pages で `main` ブランチのルートを指定するだけ。
